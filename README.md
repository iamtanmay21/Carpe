# Carpe Diem (Android Rewrite)

This project has been rewritten from Flutter to a native Android application using Kotlin and Jetpack Compose.

## Architecture
- **Framework**: Android SDK, Jetpack Compose
- **Language**: Kotlin

## Status
The core shell (MainActivity, Compose UI, App configuration) has been established. 
Due to container limitations in the provisioned environment (which was configured for the original Flutter project and lacks the Android build tools), full compilation cannot be verified locally.
